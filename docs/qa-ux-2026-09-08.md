# UX and optional web import verification

Verified against the locally built single HTML on 2026-09-08, using gstack
browse (Chromium) and the public synthetic example bank. Course banks were not
included in the manual or release changes.

## Application

- The same Next action traversed questions 1 through 10 on consecutive exams.
- Review unanswered responses moved from question 10 to the first unanswered
  question, preserved answers, and did not select an explicit `No sé` response.
- Escape dismissed the submission dialog without navigating or submitting.
- Local recovery retained the paused exam and its current question.
- Help opens with its heading focused, restores focus when dismissed, and keeps
  its close button visible while the text scrolls on a 375px-wide viewport.
- At 375px, question navigation settled below the sticky header (card top 136px,
  header bottom 116px), with no horizontal document overflow.
- The progress summary no longer clips the coverage heading at 1000px.
- The global save button exported valid content with three completed exams
  and state revision 69. Browser download fallback was exercised by disabling
  File System Access in the isolated QA tab; the resulting Blob passed the
  module validator. The UI correctly reported `Descarga iniciada`, not confirmed
  disk persistence. File System Access completion/cancellation are unit-tested.

## Optional network boundary

- A fresh application document had no resource requests on startup.
- A public raw GitHub module downloaded only after explicit form submission,
  reached the normal preview, and installed successfully.
- A normal GitHub file-view URL resolved to the same raw module.
- An HTTP URL was rejected before any network request or state replacement.
- Cancelling a remote preview preserved the existing paused exam.
- Enter in the URL field submits the load action; required and URL validation
  remain native. Cancel and Escape dismiss without loading, even with invalid
  input. Repeatable browser regression: `tests/browser/remote-import-form.sh`.
- Adapter tests cover CORS/network failures, timeout, broken streams, invalid
  JSON/UTF-8, the exact 10 MiB limit, oversize streams and redirects.
- Packaging tests retain embedded assets and CSP hashes. Only `connect-src`
  permits HTTPS for optional imports; scripts, fonts and images stay embedded.

## Manual

The eight-page PDF uses seven real screenshots with numbered annotations. The
screenshots use synthetic questions, and the guide explains file/link imports,
study, review, saving, resuming and obtaining compatible question banks.

Mobile checks are Chromium viewport checks, not a test on physical iOS hardware.
The changes do not add cloud synchronization or publish any private question bank.
